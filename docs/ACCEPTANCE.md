## 交付边界

- 当前生产站点已关联并部署到 GitHub Pages；PWA 必须从 HTTPS 公网地址安装，本地 `next dev` 不注册 Service Worker。
- 当前真实来源不需要 LLM 或用户 API Key；来源不足时定时生成会失败关闭，而不是用 demo 或旧闻补齐。
- GitHub Pages 上的 IndexedDB 按浏览器和站点域名隔离；跨设备需导出/恢复 JSON，或后续接入带 RLS 的同步后端。
- 离线缓存只保证必要界面和已访问页面可读，不保证内容为最新日报；恢复网络后采用网络优先更新。
