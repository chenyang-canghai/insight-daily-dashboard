# 内容规则

- 事实、推断、观点和未知信息分开保存与展示。
- 新闻只保存标题、元数据、必要引用、原创摘要和分析，不复制全文。
- 来源不足时减少数量；不得为了凑够 8 条或 3 条剖析而编造。
- 股票结论只使用“值得持续跟踪”“保持观察”“当前风险收益比不佳”“数据不足，暂不判断”。
- 禁止“必涨”“稳赚”“百分百”“无风险”“内幕消息”等误导性措辞。
- 无合格研究标的时输出“今日暂无达到研究标准的观察标的，建议保持观察。”
- 非交易日显示休市和最近交易日，不生成虚假当日行情。
- 真题只接受官方或已授权来源；原创题标记 `original_demo`。
- 权威原文必须能核验，系统原创总结句不能冒充引语。
