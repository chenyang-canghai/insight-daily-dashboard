# 必要假设

1. 项目先以个人使用、公开 GitHub Pages 为默认场景，不接券商、不交易、不提供个性化买卖指令。
2. 默认新闻为每天 8 条、深度剖析 3 条、行测 8 题；来源不足时允许少于目标数量并显示原因。
3. demo 内容只演示结构和交互，标题使用“演示议题”表述，行情为显式示例值，不代表 2026 年真实新闻或行情。
4. GitHub Actions 的 `schedule` 仅支持 UTC。北京时间 06:45、07:15、18:25 分别换算为 UTC 前一日 22:45、前一日 23:15、当日 10:25；脚本内再次校验 Asia/Shanghai 日期。
5. 交易日第一版使用周末规则和仓库节假日日历；节假日表需按年度更新。数据源无法确认交易日时宁可标记未知，不生成行情。
6. 国考和江西省考真题版权未逐题核验，首版只附原创 demo 题。接入真题时必须记录官方或已获授权来源。
7. GitHub Pages 的仓库名未知，部署工作流在构建时自动注入 `NEXT_PUBLIC_BASE_PATH`；本地默认为空。
8. Windows 当前没有系统级 Python/uv，项目仍提供标准 `pyproject.toml` 和 `uv.lock`；本轮验证可使用 Codex 随附 Python 运行时。
9. IndexedDB 数据按浏览器与站点源隔离。首次从用户站点迁移到自定义域名时需要导出/导入，除非启用第二阶段云同步。
