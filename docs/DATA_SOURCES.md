# 数据来源与降级

## 来源优先级

1. 政府、监管、央行、交易所、统计机构、公司公告和投资者关系页面。
2. 信誉良好的主流媒体。
3. 行业媒体、研究机构和学术机构。

社交媒体只能作为线索。重大事实原则上至少两个独立来源；能找到原始文件时优先原始文件。

## A 股

- 首选候选：AKShare；备用候选：BaoStock、交易所公开数据。
- 可选增强：Tushare（用户自行配置 Token）。
- 每个字段记录来源、数据时间、复权、单位、实时/估算/缺失状态。
- 来源冲突不静默覆盖：按注册表优先级选择，并把差异写入 `data_quality.conflicts`。

## 降级顺序

实时来源 → 备用来源 → 最近有效报告（标记 stale）→ 无数据状态。任何阶段都不得用模型训练记忆或旧值冒充当日事实。

## 频率与合规

采集器遵守 robots、服务条款、速率限制与数据再分发边界。不绕过登录、验证码或付费墙。来源登记包含联系人、用途、允许保存字段、频率和退出开关。
