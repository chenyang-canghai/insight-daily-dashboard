# 数据来源与降级

## 来源优先级

1. 政府、监管、央行、交易所、统计机构、公司公告和投资者关系页面。
2. 信誉良好的主流媒体。
3. 行业媒体、研究机构和学术机构。

社交媒体只能作为线索。重大事实原则上至少两个独立来源；能找到原始文件时优先原始文件。

## 当前新闻来源

- 国家统计局“最新发布”“数据解读”官方 RSS。
- 国家发展改革委“新闻发布”公开列表页。
- 国家数据局“数字经济”公开列表页。
- 国家互联网信息办公室“政策法规”公开列表页。
- 人力资源社会保障部新闻公开 RSS。政策解读旧 RSS 当前持续返回 403，已在来源登记中停用；恢复前必须重新验证，不绕过限制。

只保存标题、链接、发布日期、来源标识、官方 RSS 自带摘要，以及入选条目的官方详情页必要短摘；不保存网页全文。自动摘要不得超出这些证据，具体事实、数字、适用范围和因果关系仍需回到原文核验。详情页正文无法提取时，条目降级为“仅标题元数据”，不得强行生成深度剖析。

候选新闻先做当期 URL/标题去重，再与最近 14 天日报比较。本期新增永远排在前面；新增不足 8 条时，从较久未出现的旧条目中轮换补足，并明确标注“持续跟踪”和首次收录日期，不把旧闻伪装成今日新闻。真实来源当期去重后不足 8 条时仍拒绝生成。

深度剖析只从具有官方正文短摘或官方摘要的条目中选择，最多三条并优先覆盖不同主题。页面按“核心判断 → 证据底座 → 可能的传导机制 → 待核验项 → 申论转化”组织；来源不足时宁可少于三条，也不以通用模板凑数。规则生成的机制解释属于分析框架，不等于已经发生的现实效果。

## A 股

- 首选：AKShare；备用：BaoStock。两者当前均不需要仓库 Secret。
- AKShare 提供最近交易日指数、市场广度和行业快照；失败时 BaoStock 只提供可取得的指数日线，并将完整度标为 partial。
- 免费公开数据未完成财报、估值和公告双源核验时，系统固定输出“本期不选股”。
- 每个字段记录来源、数据时间、复权、单位、实时/估算/缺失状态。
- 来源冲突不静默覆盖：按注册表优先级选择，并把差异写入 `data_quality.conflicts`。

## 降级顺序

实时来源 → 备用来源 → 无数据状态。未更新模块可保留上一期用于浏览，但任务状态必须标记 stale；任何阶段都不得用模型训练记忆或旧值冒充当日事实。

## 频率与合规

采集器遵守 robots、服务条款、速率限制与数据再分发边界。不绕过登录、验证码或付费墙。来源登记包含联系人、用途、允许保存字段、频率和退出开关。
